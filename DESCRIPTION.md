Plugin Description
Short Description
An Elementor video widget for YouTube and self-hosted videos with custom thumbnails, hover preview, click playback, Dynamic Tags, loop, and auto-stop behavior.

Long Description
BDDEX Elementor Video Widget adds a clean and interactive video widget to Elementor. It supports YouTube and self-hosted videos, custom thumbnails, Elementor Dynamic Tags, ACF URL fields, muted hover previews, full video playback on click, loop settings, YouTube related-video reduction, and automatic stopping of other duplicated video widgets on the page.

The widget is built for video cards, course listings, portfolio grids, landing pages, and dynamic templates where videos should load visually with a thumbnail, preview briefly on hover, and only play fully when the visitor clicks.
